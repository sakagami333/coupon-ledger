検定クーポン発行ツール

クーポンを発行する

流れ：① 入力して「発行リストに追加」（何回でも追加できます） → ② 発行リストを確認して「まとめて発行」（1つの確認依頼＝PR になります） → ③ 部内の誰かが GitHub で確認・承認 → ④ 一覧で「マージして確定」 → ⑤ お客様へ送付

1. 発行内容を入力

今日以降の日付を選んでください。複数日開催のときは「受検日を追加」で増やします
Excel などから「組織名」または「組織名｜利用者数」の2列を複数行コピーして、組織名の欄に貼り付けると、行ごとに分かれて入ります
この画面で追加するクーポンすべてに付きます。クーポンは申込期間中に使うため、受検日より前の日付にしてください（受検日が複数あるときは、いちばん早い受検日より前）
クリックすると候補（テスト・自部門・営業部など）が出ます。自由に入力もできます
空欄のままなら、配布先ごとに「検定 配布先名」（例：クラウド検定ベーシック 株式会社サンプル）が入ります。入力した場合は、入力した内容がすべての配布先に入ります

2. 発行リスト

発行リストはこのパソコンに保存されます。途中で閉じても、続きから発行できます。
依頼元（営業部のツールなど）でコードが決まっている場合は、「コード」欄に入力してください。コードを縦に並べてコピーし、1行目の欄に貼り付けると、上から順に入ります。

発行済み一覧・確認状況

設定

管理者が最初に一度だけ設定します。ふだん使う人は触らなくて大丈夫です。

GHES は https://ホスト名/api/v3 、github.com は https://api.github.com
1クーポン＝1ファイルで「フォルダ/発行年/コード.json」に保存します
検定・区分・割引の選択肢。無ければツール内の初期値を使います
このパソコンのブラウザにだけ保存されます。リポジトリの読み書きと Pull request の作成・マージ権限が必要です
